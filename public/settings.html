Review GiGo configuration and prepare its secure multi-provider AI pool.

🔒
AI keys stay server-side.

Never paste API keys into this page, GitHub files or chat. Configure the JSON provider pool as the Cloudflare Worker secret AI_PROVIDER_POOL.

Multi-provider pool format

GiGo supports multiple providers and multiple authorised keys per provider. Only entries marked freeOnly: true are eligible. Provider rate limits remain in force; GiGo will not rotate keys to bypass a 429 limit.

[\n  {\n    "provider": "groq",\n    "keyId": "groq-project-a",\n    "baseUrl": "https://api.groq.com/openai/v1",\n    "model": "YOUR_FREE_MODEL_ID",\n    "apiKey": "YOUR_SECRET_KEY",\n    "freeOnly": true,\n    "enabled": true,\n    "priority": 1\n  }\n]

Example only. Do not enter real keys here. The router is ready for the pool; live provider and tool-calling compatibility still require testing.
