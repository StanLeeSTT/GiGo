Multi-provider pool format

GiGo supports multiple providers and multiple authorised keys per provider. Only entries marked freeOnly: true are eligible. Provider rate limits remain in force; GiGo will not rotate keys to bypass a 429 limit.

[
  {
    "provider": "groq",
    "keyId": "groq-project-a",
    "baseUrl": "https://api.groq.com/openai/v1",
    "model": "YOUR_FREE_MODEL_ID",
    "apiKey": "YOUR_SECRET_KEY",
    "freeOnly": true,
    "enabled": true,
    "priority": 1
  }
]

Example only. Do not enter real keys here. The router is ready for the pool; live provider and tool-calling compatibility still require testing.
